# همیار هیئت

سامانه ارتباطی فارسی هیئت برای اندروید و آیفون؛ با ورود اعضا، اتاق‌های گروهی و کنترل نوبت صحبت (Push-to-Talk).

## وضعیت فعلی
نسخهٔ سخت‌سازی‌شده در شاخهٔ `hardening/phase-1` توسعه یافته و هنوز با `main` ادغام یا منتشر نشده است. در این شاخه، دسترسی اتاق مدیریت به مدیر محدود شده، API مدیریت اعضا با احراز هویت مدیر اضافه شده و آزمون‌های یکپارچهٔ ورود و مجوزها به CI افزوده شده‌اند. جزئیات منابع واقعی Cloudflare و کارهای باقی‌مانده در [CLOUDFLARE_STATUS.md](./CLOUDFLARE_STATUS.md) ثبت شده است.

نسخهٔ آغازین پروژه در GitHub ثبت شده است: رابط فارسی PWA، سرور Node.js، پایگاه داده SQLite، ورود با نام و دو کد، نشست امضاشده و کنترل نوبت صحبت در اتاق‌ها. **انتقال واقعی صدا و تصویر هنوز پیاده‌سازی نشده است.** دکمهٔ PTT در این مرحله فقط نوبت صحبت را رزرو می‌کند.

## پنل مدیریت

مدیر سامانه می‌تواند از داخل پنل، اعضا را ثبت و نقش آن‌ها را تعیین کند، حساب‌ها را فعال/غیرفعال کند، اتاق جدید بسازد و اتاق‌ها را فعال/غیرفعال کند. فهرست اتاق‌های فعال برای اعضای واردشده نمایش داده می‌شود. داده‌های این پنل فعلاً در SQLite سرور Node نگهداری می‌شوند و هنوز به D1 منتقل نشده‌اند.

## کیفیت صدا

زنجیرهٔ پردازش پیشنهادی در `public/audio-processing.js` و معیارهای پذیرش در `AUDIO_QUALITY.md` ثبت شده‌اند. این زنجیره هنوز به ترک WebRTC متصل نشده است؛ انتقال صوت واقعی در حال حاضر فعال نیست.

## معماری هدف
- رابط: وب‌اپلیکیشن واکنش‌گرا و قابل نصب (PWA)
- سرور: Node.js و Express
- ارتباط بلادرنگ و کنترل نوبت: Socket.IO؛ قفل نوبت در نسخهٔ فعلی فقط در حافظهٔ یک نمونهٔ سرور است.
- پایگاه دادهٔ اولیه: SQLite با WAL؛ برای چند نمونهٔ هم‌زمان باید PostgreSQL و قفل توزیع‌شده (Redis) اضافه شود.
- رسانهٔ صوت/تصویر: WebRTC؛ برای گروه‌های پرتعداد، SFU مانند LiveKit یا mediasoup روی سرور رسانه لازم است.
- نگهداری کد: GitHub

## اجرای توسعه
نیازمند Node.js نسخهٔ 20 یا بالاتر:

```bash
cp .env.example .env
npm install
npm run dev
```

در ویندوز PowerShell:
```powershell
Copy-Item .env.example .env
npm install
npm run dev
```

سپس `http://localhost:3000` را باز کنید.

## ایجاد عضو آزمایشی
پس از اجرای یک‌بار سرور برای ایجاد پایگاه داده (یا با اجرای اسکریپت که جدول را خودکار می‌سازد)، عضو را از ترمینال همان ماشین سرور اضافه کنید:

```bash
npm run member:add -- "نام و نام خانوادگی" "کدسرپرستی" "کدشخص" member
```

برای نقش مدیر، آرگومان آخر را `admin` بگذارید. کدهای واقعی اعضا را در GitHub، پیام‌رسان یا فایل عمومی قرار ندهید. این فرمان فقط برای راه‌اندازی اولیه از طریق خط فرمان است؛ API مدیریت اعضا و رابط اولیهٔ مدیر در شاخهٔ سخت‌سازی اضافه شده‌اند؛ این تغییرات هنوز به شاخهٔ اصلی منتشر نشده‌اند.

## امنیت و استقرار
- `SESSION_SECRET` باید یک راز تصادفی و محرمانه با حداقل ۳۲ نویسه باشد.
- برای استفادهٔ واقعی، HTTPS، پشتیبان‌گیری، پایش سرور، مدیریت امن اعضا و بازبینی امنیتی الزامی است.
- سرور فقط اتاق‌های فعال را می‌پذیرد؛ اتاق مدیریت فقط برای مدیر فعال است؛ وضعیت حساب و نقش در رویدادهای حساس سوکت دوباره بررسی می‌شود؛ غیرفعال‌کردن عضو اتصال‌های فعال او را قطع می‌کند؛ تغییر اتاق عضویت قبلی را آزاد می‌کند؛ ظرفیت اتاق و محدودیت نرخ PTT اعمال می‌شوند؛ عملیات مدیریتی در گزارش حسابرسی ثبت می‌شود.
- قفل صحبت با heartbeat تمدید می‌شود و در قطع اتصال، ترک اتاق یا مخفی‌شدن صفحه آزاد می‌شود. این قفل هنوز برای چند نمونهٔ سرور توزیع‌شده نیست.
- SQLite برای شروع مناسب است؛ در مقیاس بالاتر باید مهاجرت به PostgreSQL بررسی شود.
- Dockerfile برای ساخت کانتینر برنامهٔ وب وجود دارد.
- سرور رسانهٔ WebRTC و TURN باید جداگانه و متناسب با ظرفیت و کیفیت اینترنت راه‌اندازی شود.

## محدودیت‌های موبایل و اینترنت
- PTT در این نسخه فقط زمانی که صفحه باز و اتصال برقرار است کنترل می‌شود؛ صدای واقعی هنوز منتقل نمی‌شود. در نتیجه این نسخه هنوز بی‌سیم صوتی عملیاتی نیست.
- مرورگر موبایل پخش/ضبط دائمی صدا در پس‌زمینه یا هنگام خاموش بودن گوشی را تضمین نمی‌کند.
- گوشی خاموش یا بدون اینترنت نمی‌تواند صدای زنده دریافت کند.
- تماس ورودی پس‌زمینه نیازمند Push و برای تجربهٔ قابل اتکا، اپ بومی با مجوزها و سازوکارهای مجاز iOS/Android است.
- GitHub فقط محل نگهداری کد است و سرور ۲۴ساعته ارائه نمی‌کند. سرور مجازی رایگان پایدار و ظرفیت ۱۰۰ نفر تضمین‌شده نیست. برای دسترسی داخل ایران باید میزبانی، دامنه و مسیرهای ارتباطی عملاً از اپراتورهای مختلف آزمایش شوند.

## مجوز
مجوز پروژه هنوز تعیین نشده است؛ پیش از انتشار عمومی، مالک پروژه باید مجوز را انتخاب کند.

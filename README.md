# همیار هیئت

سامانه ارتباط صوتی فارسی اعضای هیئت با اتاق‌های مجزا، ورود اختصاصی و کنترل نوبت صحبت (Push-to-Talk).

## وضعیت فعلی

- **Worker تولیدی:** [test2.mahdi-masoumi168.workers.dev](https://test2.mahdi-masoumi168.workers.dev)
- **زیرساخت:** Cloudflare Workers، D1، Durable Objects و Cloudflare Realtime SFU.
- **رابط وب:** PWA فارسی؛ فایل‌های رابط فعلی همراه نسخه Worker منتشر شده‌اند.
- **ورود:** نام و نام خانوادگی، کد سرپرستی و کد شخص.
- **صوت:** مسیر WebRTC/SFU و کنترل نوبت PTT پیاده‌سازی و روی Worker منتشر شده است؛ کیفیت و پایداری تماس هنوز باید روی چند گوشی و شبکه واقعی آزمایش شود.
- **مدیر اولیه:** هنوز در پایگاه داده ساخته نشده است.
- **اپ بومی:** کلاینت Flutter برای Android و iOS در پوشه `mobile/` قرار دارد؛ آخرین CI هر دو build آزمایشی Android و unsigned iOS را با موفقیت ساخته است. نصب نهایی iOS به امضای Apple نیاز دارد و تماس صوتی و پس‌زمینه باید روی گوشی واقعی آزمایش شوند.

**این سامانه هنوز تأیید نهایی عملیاتی نشده است.** قبل از استفاده در هیئت باید مدیر اولیه ساخته شود و تماس صوتی با حداقل دو دستگاه واقعی آزمایش شود.

## معماری

- رابط وب: PWA فارسی و قابل نصب.
- API و احراز هویت: Cloudflare Worker.
- پایگاه داده اصلی: Cloudflare D1 با binding به نام `DB`.
- اتاق‌ها و حضور اعضا: Durable Objects با کلاس‌های `RoomHub` و `GlobalPresence`.
- انتقال صوت: WebRTC از طریق Cloudflare Realtime SFU.
- NAT traversal: STUN/TURN؛ شناسه و Secret مربوط به TURN در Worker تنظیم شده‌اند.
- اپ بومی: Flutter، `flutter_webrtc` و `audio_service` برای دریافت صوت در پس‌زمینه با محدودیت‌های Android و iOS.

## ساخت و آزمایش Worker

نیازمند Node.js نسخه 20 یا بالاتر:

```bash
npm install
npm run assets:embed
npm test
npx wrangler deploy --dry-run --config wrangler.jsonc
```

برای انتشار واقعی، حساب Cloudflare باید به Wrangler متصل باشد و Secretهای محیط تولیدی در تنظیمات Worker نگهداری شوند. مقدار Secretها را در GitHub یا فایل عمومی قرار ندهید.

## ساخت اپ Android و iOS

راهنمای کامل ساخت بومی، مجوزهای میکروفون، تنظیمات صوت پس‌زمینه و محدودیت‌های سیستم‌عامل در [mobile/README.md](mobile/README.md) قرار دارد.

## راه‌اندازی مدیر اولیه

پایگاه داده تولیدی در حال حاضر هیچ کاربر ثبت‌شده‌ای ندارد. نخستین مدیر باید فقط یک بار از [صفحه راه‌اندازی امن مدیر اولیه](https://test2.mahdi-masoumi168.workers.dev/setup.html) ساخته شود. کلید راه‌اندازی اولیه را در مخزن یا کد برنامه قرار ندهید؛ آن را فقط در این فرم امن وارد کنید. پس از ایجاد مدیر، endpoint دیگر اجازه ساخت مدیر اولیه را نمی‌دهد.

## امنیت و محدودیت‌ها

- کدهای ورود به‌صورت هش‌شده در D1 نگهداری می‌شوند؛ مقدار خام کدها در مخزن قرار نمی‌گیرد.
- نشست‌ها امضا می‌شوند و وضعیت عضویت در هر اتصال بررسی می‌شود.
- PTT فقط با نگه‌داشتن دکمه میکروفون را فعال می‌کند؛ با رهاکردن دکمه، قطع اتصال یا رفتن برنامه به پس‌زمینه، نوبت صحبت آزاد می‌شود.
- مرورگر موبایل دریافت صدای پایدار در پس‌زمینه یا هنگام خاموش بودن صفحه را در همه دستگاه‌ها تضمین نمی‌کند؛ برای این نیاز از اپ بومی استفاده شود.
- بستن اجباری برنامه، خاموش بودن گوشی یا قطع اینترنت می‌تواند دریافت صوت زنده را متوقف کند.
- ظرفیت ۱۰۰ عضو هم‌زمان تا پیش از تست بار و اندازه‌گیری مصرف Realtime تضمین‌شده نیست.
- پشتیبان‌گیری D1، آزمون بازیابی، پایش خطا و تست شبکه‌های مختلف باید پیش از بهره‌برداری منظم شوند.

## ساختار پوشه‌ها

- `cloudflare/`: کد Worker، Durable Objects، تست‌ها و schema پایگاه داده.
- `public/`: فایل‌های منبع رابط PWA.
- `cloudflare/src/embedded-assets.js`: فایل‌های رابط وب که در Worker بسته‌بندی می‌شوند.
- `scripts/embed-assets.js`: تولید ماژول دارایی‌ها از پوشه public.
- `mobile/`: اپ بومی Flutter برای Android و iOS.
- `wrangler.jsonc`: تنظیمات Worker، D1، Durable Objects و دارایی‌ها.
- `CLOUDFLARE_STATUS.md`: وضعیت استقرار و موارد باقی‌مانده.

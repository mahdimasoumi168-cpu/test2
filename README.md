# همیار هیئت

سامانه ارتباطی فارسی هیئت برای اندروید و آیفون؛ با ورود اعضا، پیام‌رسانی، اتاق‌های گروهی و ارتباط صوتی فشاری (Push-to-Talk).

## وضعیت فعلی
این مخزن، اسکلت نسخهٔ اولیه (MVP) است. رابط کاربری و زیرساخت اولیه آماده‌سازی شده‌اند؛ تماس صوتی/تصویری واقعی، اعلان پس‌زمینه و استقرار عملیاتی هنوز نیازمند پیاده‌سازی و آزمون هستند.

## معماری هدف
- رابط: وب‌اپلیکیشن واکنش‌گرا و قابل نصب (PWA)
- سرور: Node.js و Express
- ارتباط بلادرنگ و سیگنالینگ: Socket.IO
- پایگاه دادهٔ اولیه: SQLite
- ارتباط صوتی: WebRTC؛ برای گروه‌های پرتعداد بهتر است در مرحلهٔ بعد SFU مانند LiveKit یا mediasoup روی سرور مستقل نصب شود.
- نگهداری کد: GitHub

## اجرای توسعه
نیازمند Node.js نسخهٔ 20 یا بالاتر:

```bash
cp .env.example .env
npm install
npm run dev
```

سپس نشانی `http://localhost:3000` را باز کنید.

در ویندوز PowerShell:
```powershell
Copy-Item .env.example .env
npm install
npm run dev
```

## ورود و امنیت
ورود با نام، کد سرپرستی و کد شخص طراحی شده است. کدهای واقعی اعضا نباید در GitHub یا فایل‌های عمومی قرار گیرند. در نسخهٔ عملیاتی، مدیر باید حساب‌ها را از مسیر امن ایجاد کند و کدها به‌صورت هش‌شده ذخیره شوند. این نسخهٔ اولیه ورود آزمایشی را پیاده‌سازی می‌کند؛ برای استفادهٔ واقعی، HTTPS، محدودیت تلاش ورود، سیاست پشتیبان‌گیری و مدیریت کلیدها الزامی است.

## محدودیت مهم تماس
- PTT در حالی کار می‌کند که صفحهٔ برنامه باز و میکروفون در دسترس باشد.
- مرورگرهای موبایل اجازهٔ پخش/ضبط صوت دائمی پس‌زمینه یا هنگام خاموش بودن گوشی را تضمین نمی‌کنند.
- گوشی خاموش یا بدون اینترنت نمی‌تواند صدای زنده دریافت کند.
- برای تماس ورودی در پس‌زمینه باید Push و در اپ بومی، سازوکارهای مجاز iOS/Android جداگانه پیاده‌سازی شوند.
- سرویس رایگان و سرور مجازی رایگان با پایداری ۲۴ساعته و ظرفیت ۱۰۰ نفر تضمین‌شده نیست. GitHub محل کد است، نه سرور اجرای سامانه.

## استقرار
برای استقرار عمومی، یک VPS با IP/دامنه، HTTPS و پیکربندی فایروال لازم است. فایل Dockerfile برای اجرای سرویس وب اضافه شده است. سرور رسانهٔ WebRTC و TURN باید جداگانه و متناسب با ظرفیت راه‌اندازی شود.

## مجوز
فعلاً مجوز پروژه تعیین نشده است؛ پیش از انتشار عمومی، مالک پروژه باید مجوز را انتخاب کند.

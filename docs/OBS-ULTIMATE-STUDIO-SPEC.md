# OBS Ultimate Studio — مشخصات فنی نسخه جامع

## هدف
تبدیل پروژه فعلی اتاق فرمان هیئت به یک نرم‌افزار دسکتاپ‌محور و فارسی برای کنترل OBS Studio، تولید رسانه، مدیریت صدا، پخش زنده، ضبط و اتوماسیون مراسم. OBS موتور اصلی تصویر و خروجی است؛ پنل نقش مرکز فرمان را دارد.

## اصول معماری
- حفظ قابلیت‌های فعلی پروژه و توسعه تدریجی؛ حذف یا بازنویسی مخرب بدون نسخه پشتیبان ممنوع.
- لایه ارتباطی مستقل برای OBS WebSocket v5 با مدیریت اتصال، احراز هویت، صف درخواست، timeout، reconnect و ثبت خطا.
- تفکیک رابط کاربری از سرویس‌های OBS و سرویس‌های جانبی.
- تشخیص نسخه OBS و قابلیت‌های در دسترس؛ قابلیت ناسازگار باید غیرفعال و علت آن نمایش داده شود.
- هیچ کنترل نمایشی بدون اتصال به عملیات واقعی ارائه نشود.
- تنظیمات، پروفایل‌ها و سناریوها به‌صورت محلی ذخیره و قابل پشتیبان‌گیری باشند.
- رمز WebSocket در کد سمت مرورگر ثابت قرار نگیرد؛ دریافت امن و نگهداری محلی لازم است.
- هدف استقرار اولیه: Windows PC؛ طراحی ماژولار برای توسعه کنترل‌گر شبکه‌ای در آینده.

## ماژول‌ها

### 1. داشبورد و وضعیت کلی
- اتصال OBS، نسخه، وضعیت WebSocket و زمان اتصال
- وضعیت Stream، Record، Replay Buffer و Virtual Camera
- صحنه Program و Preview
- نرخ فریم، زمان اجرا، افت فریم و وضعیت خروجی در صورت پشتیبانی
- هشدارهای قابل تشخیص و گزارش رویدادها

### 2. کارگردانی تصویر
- فهرست و مدیریت Scene و Scene Collection در محدوده API
- ساخت، حذف و تغییر نام صحنه
- Scene Items: افزودن، حذف، نمایش، مخفی‌سازی، قفل، جابه‌جایی ترتیب
- Transform: موقعیت، اندازه، چرخش، Crop، Bounds و Alignment
- Studio Mode: Preview/Program، انتقال Cut و Transition
- مدیریت Transitionها و مدت انتقال
- Multiview و Projector در صورت دسترسی از API بومی/افزونه
- چیدمان‌های آماده و صحنه امن اضطراری

### 3. مدیریت منابع و رسانه
- افزودن Input بر اساس نوع‌های نصب‌شده در OBS
- دوربین، کپچر کارت، تصویر، ویدئو، صدا، مرورگر، متن، رنگ و گروه
- تنظیمات اختصاصی منبع، فیلترهای منبع و وضعیت فعال
- کتابخانه رسانه، دسته‌بندی، جست‌وجو و پیش‌نمایش فایل
- Playlist و صف پخش رسانه
- کنترل Media: Play/Pause/Restart/Stop/Next/Previous در منابع پشتیبانی‌شده
- متن، زیرنویس، لوگو، نشانگر و گرافیک روی تصویر

### 4. میکسر Broadcast
- فهرست ورودی‌های صوتی و کنترل Volume/Mute/Balance
- متر سطح صدای لحظه‌ای با رویداد InputVolumeMeters
- مانیتورینگ هدفون و خروجی، در حد قابلیت‌های OBS
- فیلترها: Gain، Compressor، Limiter، Noise Gate، Expander، Noise Suppression و VST در صورت نصب
- کنترل تنظیمات فیلتر با schema واقعی هر فیلتر؛ عدم فرض پارامترهای مشترک
- پروفایل‌های صوتی برای مداحی، سخنرانی، تلاوت و مراسم
- اولویت سرپرست با طراحی میکس/ducking و تنظیم gain کنترل‌شده؛ جلوگیری از clipping و limiter نهایی
- Push-to-talk / Push-to-mute و hotkeys در صورت پشتیبانی
- توجه: پردازش پیشرفته، mix-minus و routing مستقل ممکن است به پلاگین یا موتور صوتی جداگانه نیاز داشته باشد.

### 5. پخش، ضبط و خروجی
- شروع/توقف پخش و نمایش وضعیت، مدت، bitrate و خطا
- تنظیم Stream Service و Server/Key با نمایش امن و عدم ثبت کلید در log
- چند خروجی مستقل فقط در صورت پشتیبانی واقعی OBS/plugin/encoder؛ در غیر این صورت راهکار چندمقصدی مشخص و مستند
- شروع/توقف/مکث ضبط، مسیر و کیفیت در حد API
- Replay Buffer: شروع، توقف و ذخیره کلیپ
- Virtual Camera
- تنظیم Encoder، کیفیت، رزولوشن و FPS در محدوده تنظیمات قابل‌دسترسی
- ثبت فصل و Split Recording در صورت پشتیبانی API بومی

### 6. اتوماسیون مراسم
- سناریوهای قابل ساخت و ذخیره
- گام‌ها: تغییر صحنه، نمایش/مخفی‌سازی منبع، پخش رسانه، تنظیم صدا، نمایش عنوان و تأخیر
- اجرای مرحله‌ای، توقف، لغو و ادامه
- زمان‌بندی با ساعت محلی و تأیید اپراتور
- دکمه اضطراری: قطع موسیقی، انتخاب صحنه امن و حفظ صدای ضروری

### 7. ابزارهای تکمیلی
- ساعت، شمارش معکوس و تایمر مراسم
- عنوان‌ساز، زیرنویس و نوار اطلاع‌رسانی
- مدیریت نشان/لوگو و اسلایدهای آماده
- فهرست پخش میان‌برنامه
- نشانگر وضعیت اینترنت و هشدار قطع ورودی
- ثبت رویدادها و گزارش عملکرد اپراتور
- پشتیبان‌گیری و بازیابی تنظیمات و سناریوها

### 8. امنیت و پایداری
- رمز ورود پنل به‌صورت hash و مدیریت نشست؛ رمز ثابت در JavaScript قابل قبول نیست.
- رمز OBS WebSocket فقط در تنظیمات محلی امن؛ هرگز در مخزن Git یا فایل عمومی.
- احراز هویت OBS WebSocket فعال و شبکه فقط روی localhost مگر نیاز مشخص به LAN.
- تأیید عملیات پرخطر مانند توقف پخش، حذف منبع و تغییر مقصد.
- محدودیت نرخ درخواست، مدیریت reconnect و جلوگیری از درخواست‌های هم‌زمان ناسازگار.
- گزارش خطا بدون افشای Stream Key یا password.
- نسخه پشتیبان قبل از تغییرات عمده.

## مرزبندی فنی
OBS WebSocket تمام قابلیت‌های داخلی رابط گرافیکی OBS را پوشش نمی‌دهد. هر قابلیت باید به یکی از سه دسته علامت‌گذاری شود:
1. قابل اجرا با OBS WebSocket؛
2. نیازمند OBS Frontend API یا افزونه بومی؛
3. نیازمند ابزار جانبی مستقل یا غیرقابل اجرا در محیط فعلی.
این محدودیت‌ها باید در رابط کاربری روشن باشند و قابلیت شبیه‌سازی‌شده به‌عنوان قابلیت واقعی نمایش داده نشود.

## مراحل اجرا و معیار پذیرش
1. تثبیت پایه: پشتیبان‌گیری، بازبینی اتصال، احراز هویت، سازگاری نسخه و تست قطع/وصل.
2. هسته OBS: صحنه‌ها، منابع، Transform، Studio Mode و Transitionها.
3. صوت Broadcast: meters لحظه‌ای، volume/mute، فیلترهای قابل تنظیم و پروفایل صوتی.
4. خروجی: Stream، Record، Replay Buffer، Virtual Camera و آمار.
5. استودیوی رسانه: کتابخانه، Playlist، متن، زیرنویس و گرافیک.
6. اتوماسیون و ابزارهای جانبی.
7. آزمون یکپارچه روی OBS واقعی و رفع خطاها.

هر مرحله فقط پس از تست عملی روی OBS و تأیید عملیات واقعی، «تکمیل‌شده» محسوب می‌شود.

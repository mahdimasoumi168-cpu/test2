# اپ بومی همیار هیئت

این پوشه کلاینت بومی Android/iOS است؛ برای دریافت صدای WebRTC در زمان قفل صفحه از AudioService و تنظیمات صوت پس‌زمینه سیستم‌عامل استفاده می‌کند. میکروفون فقط هنگام نگه‌داشتن دکمه صحبت درخواست می‌شود و با رفتن برنامه به پس‌زمینه، نوبت صحبت آزاد می‌شود.

## ساخت پروژه‌های Android و iOS

در سیستمی که Flutter stable و Python 3 نصب است:

```bash
cd mobile
bash bootstrap.sh
flutter pub get
flutter analyze
flutter test
```

اسکریپت، پوشه‌های بومی Android و iOS را با Flutter تولید می‌کند، سپس مجوزهای میکروفون، سرویس foreground صوتی Android، و حالت background audio در iOS را تنظیم می‌کند.

## اجرا

```bash
flutter run --dart-define=API_BASE_URL=https://test2.mahdi-masoumi168.workers.dev
```

نشانی بالا فقط پس از استقرار Worker قابل استفاده است. در وضعیت فعلی Worker عمومی هنوز نسخه اجرایی API را ارائه نمی‌کند.

## نکات پس‌زمینه و محدودیت‌ها

- Android: هنگام اتصال به اتاق، AudioService اعلان پایدار رسانه‌ای و foreground service از نوع `mediaPlayback` را فعال می‌کند. کاربر باید اعلان را ببیند و مجوز اعلان را بدهد.
- iOS: حالت `audio` در `UIBackgroundModes` فعال می‌شود. ادامه دریافت صدا به سیاست‌های iOS، وضعیت صوتی واقعی، شبکه و تنظیمات دستگاه وابسته است و باید روی آیفون واقعی آزمایش شود.
- بستن اجباری برنامه، خاموش بودن گوشی، قطع اینترنت یا خروج از اتاق، دریافت صدای زنده را متوقف می‌کند. این نسخه هنوز PushKit/CallKit برای بیدارکردن برنامه پس از بسته‌شدن اجباری ندارد.
- امضای انتشار iOS و نصب نهایی روی دستگاه نیازمند حساب/گواهی توسعه‌دهنده Apple است.
- هیچ ادعای پایداری پس‌زمینه یا کیفیت تماس پیش از آزمایش واقعی چند دستگاه ثبت نمی‌شود.

## امنیت

توکن نشست فقط در حافظه برنامه نگهداری می‌شود و در SharedPreferences یا فایل متنی ذخیره نمی‌شود. کدهای سرپرستی و شخص نیز پس از ورود در حافظه فرم باقی می‌مانند تا صفحه بسته شود؛ در نسخه انتشار باید فرم پس از ورود پاک شود.
